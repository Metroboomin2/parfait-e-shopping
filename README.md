# 🛍️ Parfait E‑Shopping

A complete multi-role e-commerce website with Admin, Seller, Customer. Prices in **USD ($)**.

## Installation

1. Clone or download files into `htdocs/parfait-e-shopping`
2. Import `database.sql` into MySQL (phpMyAdmin)
3. Copy `config.sample.php` to `config.php`
4. Ensure `uploads` folder is writable
5. Access at `http://localhost/parfait-e-shopping/`

## Create Admin

- Register as Seller, then in phpMyAdmin change role to `admin`.

## Features

- Seller: upload products + documents, set location
- Customer: order, comment, download files
- Admin: full oversight
